Source folder: Idiophones/Struck Idiophones/Tubular Bells 1/
Note naming: the source names notes with C3 = middle C (MIDI 60), so e.g. a source file named C4 is MIDI 72 here. A chime's strike note is heard rather than measured, so the octave was checked against the partials and against the usual orchestral chime range (C4–F5); the files are not retuned.

Changes made for the MIDI Field Guide (midi.community): trimmed (leading silence removed), converted to mono, level-normalized, shortened to at most 4.0 s with a fade-out, and MP3-encoded (96 kbps, 44.1 kHz).
