Source path pattern: Woodwinds/Flute/susvib/LDFlute_susvib_<note>_v1_1.wav
Note naming: the source names notes with C3 = middle C (MIDI 60), so e.g. a source file named C4 is MIDI 72 here (verified by pitch analysis).

Changes made for the MIDI Field Guide (midi.community): trimmed (leading silence removed, cut to at most 3 s with a short fade-out), converted to mono, level-normalized, and MP3-encoded (96 kbps, 44.1 kHz).
